# 剑桥大学趣味介绍网页 — 项目计划

## 项目概述
为小朋友打造一个游戏化、交互式的剑桥大学介绍网页，融合趣味知识、互动游戏和可爱视觉设计。

## 阶段规划

### Stage 1: 设计阶段
- **技能**: vibecoding-webapp-swarm
- **任务**: 
  - 研究剑桥大学趣味知识点（学院、历史、名人、趣闻）
  - 设计整体视觉风格（儿童友好、色彩鲜艳、卡通风格）
  - 设计游戏化交互流程
  - 产出 design.md 设计文档

### Stage 2: 开发阶段
- **技能**: vibecoding-webapp-swarm
- **任务**:
  - 初始化 React + TypeScript + Tailwind 项目
  - 开发多个互动游戏模块：
    1. **欢迎首页**: 动画角色引导，开始探险按钮
    2. **校园探索地图**: 点击各学院弹出趣味知识卡片
    3. **知识问答闯关**: 多选题闯关游戏，答对加分
    4. **名人连连看**: 匹配剑桥名人和他们的成就
    5. **记忆翻牌游戏**: 剑桥地标主题记忆卡配对
    6. **毕业证书**: 完成所有游戏后生成虚拟证书
  - 使用 Framer Motion 做动画
  - 使用 HTML5 Canvas 或 DOM 游戏逻辑

### Stage 3: 部署阶段
- **技能**: vibecoding-webapp-swarm
- **任务**: 构建并部署为静态网站

## 技术栈
- React + TypeScript + Tailwind CSS
- Framer Motion（动画）
- 自定义游戏逻辑（纯 React state + DOM）
- shadcn/ui 组件

## 输出
- 部署后的可访问网站 URL
